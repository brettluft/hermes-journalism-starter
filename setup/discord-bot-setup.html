Connect Discord to Hermes

This helper generates the bot invite and Railway variable names. It runs entirely in your browser and never asks for your bot token.

Discord does not let third-party tools create an application or retrieve its token automatically. Those two actions must happen inside your logged-in Discord Developer Portal. This keeps your token out of the setup page.

1Create the application

  1. Open the Developer Portal and choose New Application.
  2. Give it a newsroom-specific name, such as Example Newsroom Hermes.
  3. Open Bot. Under Token, choose Reset Token, then copy the Bot Token into a password manager.
  4. On the same page, enable Message Content Intent.
  5. Open General Information and copy the Application ID.
Open Discord Developer Portal

Use the Bot Token for DISCORD_BOT_TOKEN. Do not use the Public Key, Client Secret, or Application ID as the token.

2Generate the bot invite

Invite bot to Discord

The invite asks only for View Channels, Send Messages, Send Messages in Threads, Embed Links, Attach Files, Read Message History, and Add Reactions. It does not ask for Administrator.

3Choose the allowed channels

  1. In Discord, open User Settings, then Advanced, and enable Developer Mode.
  2. Right-click the private newsroom channel and choose Copy Channel ID.

To allow more than one channel, enter the IDs separated by commas.

4Add the Railway variables

Paste the Bot Token directly into Railway. Do not paste it into this page.

This starter allows any human member of the listed channel to use Hermes. By default, direct messages are denied. An operator can change that later through allowlists, allow-all flags, or an approved Hermes pairing. Replies stay in the channel and do not require an @mention.
